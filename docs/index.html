Download

Download for WindowsShrinkVideo-Setup.exe · Windows 10 and 11
  1. Run the downloaded file. No administrator rights are needed.
  2. Leave "install ffmpeg" ticked if it is offered. It is the engine that does the work.
  3. Right-click a video and choose Shrink video. On Windows 11 it is under Show more options (or hold Shift while right-clicking).

Windows may say "Windows protected your PC" because the installer is not code-signed. Click More info, then Run anyway.

Download for macOSShrinkVideo-macOS.pkg · Intel and Apple Silicon
  1. Open the downloaded file. macOS will warn that it is not from an identified developer: go to System Settings > Privacy & Security and click Open Anyway (on older versions: right-click the file and choose Open).
  2. Install ffmpeg, the engine that does the work: get Homebrew, then run brew install ffmpeg in Terminal.
  3. Right-click a video in Finder and choose Quick Actions > Shrink Video.

Prefer the Terminal? This installs it for your user only, with no warning to click through:

curl -fsSL https://raw.githubusercontent.com/srlegrand/shrink-video/main/macos/install.sh | bash
Download for LinuxShrinkVideo-x86_64.AppImage · Dolphin, Nautilus, Nemo
  1. Make the file executable (Properties > Permissions, or chmod +x) and double-click it.
  2. Click Install. Make sure ffmpeg is installed, for example sudo apt install ffmpeg.
  3. Right-click a video and choose Shrink video (in GNOME Files: Scripts > Shrink video).

Other architectures, or no AppImage please:

curl -fsSL https://raw.githubusercontent.com/srlegrand/shrink-video/main/linux/install.sh | bash

You decide how it gets smaller

After you pick a size, tick what Shrink Video is allowed to do. It then works out the mix that hurts least while still fitting, and remembers your choice.

Resizing

Lower the resolution, for example 1080p to 720p.

Compressing

Lower the picture quality a little.

Dropping the framerate

Fewer frames per second, for example 60 to 30.

Speeding it up

Play faster, up to 4x, so there is less video to store.

Good to know

What happens to my original video?

Nothing. Shrink Video writes a new file next to it, such as holiday_20MB.mp4 (H.264 video and AAC audio, which plays everywhere).

Is my video sent anywhere?

No. Everything runs on your own computer using ffmpeg. There is no account, no tracking and no internet connection involved.

Why does my computer warn me about the installer?

Signing certificates from Microsoft and Apple cost money every year, and this is a free project. The installers are built automatically by GitHub from the public source code, which is only a few short scripts you can read yourself.

How do I remove it?

Windows: Settings > Apps > Installed apps > Shrink Video > Uninstall.
macOS: run the Terminal command above with | bash -s -- --uninstall at the end.
Linux: double-click the AppImage again and choose Remove.

It says the video is too long to fit

Very long videos cannot fit in very small sizes and still be watchable. Pick a larger size, or tick more methods, especially "Speeding it up" and "Dropping the framerate".
